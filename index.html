01 · Overview

What this build does

The Local-FortiGate turns six department identities into an enforceable policy matrix, then adds controlled internet access and a published internal web server.

▦

Segmentation

Eight explicit deny rules isolate Technology & Innovation, Corporate Services, Engineering & Design and the executive/maintenance boundary before any allow rule is evaluated.

◷

Time-based access

Weekday internet access is split into 08:00–12:00 and 13:00–17:00. A separate 12:00–13:00 break policy relaxes only the social-networking restriction.

◈

Filtering & control

FortiGuard category filtering, SafeSearch enforcement, application control for P2P/anonymisers/remote access, and business-first traffic shaping.

⇄

NAT

Overloaded source NAT through 10.200.2.100–120 for outbound sessions, and a static VIP that publishes 10.0.1.20 on TCP/8080 → 80.

Lab limitation, stated honestly. Corporate Services, Engineering & Design and Maintenance & Support share 10.200.1.0/24 on port1. Traffic between them is switched and never reaches the FortiGate, so the production design calls for one VLAN per department. The simulator marks those paths as L2 · not inspected.

    08 · Implementation

    Build order matters

    Objects → groups → schedules → profiles → shapers → IP pool → VIP → policies → verification → backup. Each policy references objects that must already exist.

    Configuration evidence

    Browser chrome and the university lab header have been cropped; no student identifiers, credentials or private keys are included.

    09 · Deployment notes

    Verification notes from the export

    A good implementation report records what to check next. These notes compare the sanitised FortiOS export with the design intent.

    Academic project. This repository documents a Netlab+ Part B implementation. It is not a production change record. The exported configuration has been reduced to the firewall, address, NAT, schedule, shaper and policy objects; passwords, private keys, certificates, admin accounts and lab serial numbers are excluded.
